Functional Design and NFR Requirements completed authoring, native sensor validation, and independent technical review. The run reached its time limit while drafting NFR Design, before CG, full build/test, or CI generation. This trial does not establish that the live model generated buildable, testable code.

Original inputs were preserved. Incomplete work was not accepted as success: the final state was `failed` due to the time limit. See the [machine-readable results](results/2026-09-16-luna-max.json).

## Integration issues fixed during the trials

### 1. Stage-specific traceability

The first Functional Design passed the native sensor but failed the integration gate. The gate required CG-specific NFR IDs from Functional Design and interpreted targets referencing BRs as filenames.

Validation was changed to resolve IDs per stage and use the native sensor. Immediately before CG, derived BR and detailed NFR IDs are resolved using native rules. Original parked state and artifacts are projected into a private directory without changing original state, approvals, or audits.

The actual Luna artifact remains a regression test. It passes; adding an unmapped BR is detected.

### 2. The 2 MB verbose-log limit

The next attempt passed Functional Design artifact validation but hit a 2 MB output limit at review startup. The old wrapper reported output limits as `timedOut`, and a later missing-report error obscured the original cause.

TAKT output now goes to files, with the last 64,000 characters retained in memory. Output limits and timeouts are reported separately, and original execution errors take priority. The final attempt did not stop for this output limit.

## Reproduction and next improvements

```sh
bun run experiment:construction-phase -- --live
```

The current execution limit is one hour. Candidate improvements are selecting original material needed by each stage/role and reducing repeated reading/comparison, while retaining native stage definitions and quality targets.

Extending the time limit is another option, but this alone has not been shown to achieve a practical runtime. Mid-run resumption and importing artifacts into original AI-DLC remain unimplemented.
